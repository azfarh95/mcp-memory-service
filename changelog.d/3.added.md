- **The Voyage cloud embedding backend now runs with a parallel local fallback index (#3).**
  `MCP_MEMORY_EMBED_BACKEND=voyage` (the new default) embeds through Voyage AI while a
  local `all-MiniLM-L6-v2` index is maintained alongside it, in its own database file
  because sqlite-vec bakes the vector dimension into the table (1024 vs 384). Semantic
  search reads the Voyage index and degrades to the local one — flagged per result — when
  Voyage is unreachable, rather than losing search. A corpus-coverage gate keeps reads on
  the local index until the Voyage index has actually been backfilled.
  `scripts/maintenance/voyage_backfill.py` populates the Voyage index resumably.
  Keyless installs fall back to local embeddings with a warning instead of failing to
  start, and an explicitly selected Voyage backend without a key still fails loudly.
